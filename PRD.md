# AlgoScore - Tinyfish powered ai Job Portal

Build a TinyFish-powered job and internship finder. Pull live openings from company careers pages and job portals, match them to what the user is looking for (role, location, seniority, visa), and keep the results fresh. You're on careers portals every week anyway, so build the tool you'd actually use.


## Requirements
- User can set their own preferences (role, location, keywords)
- Pulls openings from multiple live careers pages or job portals
- Returns structured, deduplicated listings with links to apply
- Uses TinyFish meaningfully to discover and read listings
- Uses live web data rather than hardcoded listings
- Works across multiple companies or portals
- Works for different roles, locations, and inputs
- Filters, matches, or ranks results rather than dumping raw pages
